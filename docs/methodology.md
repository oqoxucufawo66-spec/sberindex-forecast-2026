# Методологический отчёт (черновик)

*Документ будет дополняться по мере получения результатов.*

## 1. Постановка задачи

- Объект: помесячные безналичные потребительские расходы в муниципальных образованиях (данные СберИндекса), в разрезе категорий трат.
- Задача А — прогноз значения ряда на горизонтах h ∈ {1, 3, 6, 12} месяцев.
- Задача Б — раннее обнаружение точек структурных изменений (шоков).
- Ориентир качества — Prophet; основная метрика — MAE, дополнительная — R².

## 2. Подготовка данных

- Приведение к формату «МО × категория × месяц».
- Учёт преобразований МО (объединение / разделение) по датасету СберИндекса о границах и изменениях МО.
- Обработка пропусков и коротких рядов (порог `data.min_history` в конфиге).

## 3. Модели прогнозирования

- Базовые: наивная, сезонно-наивная, Prophet (параметры — `configs/default.yaml`).
- Глобальный LightGBM с прямой стратегией (отдельная модель на горизонт).
- Фундаментальные модели (Chronos-Bolt, zero-shot).
- Схема валидации: rolling origin, без утечки будущего.

## 4. Обнаружение структурных изменений

- Офлайн: PELT и Binary Segmentation — разметка истории.
- Онлайн: CUSUM по стандартизованным остаткам прогноза — раннее предупреждение.
- Метрики: precision / recall / F1 с допуском, средняя задержка обнаружения.

## 5. Интеграция новостей

- Привязка к МО по топонимам и к месяцу по дате публикации; только прошлые новости относительно точки прогноза.
- Проверка пользы абляцией.
