# Ноутбуки

Здесь будут ноутбуки с разведочным анализом и разбором примеров:

- `01_eda.ipynb` — структура данных, пропуски, сезонность по категориям;
- `02_backtest.ipynb` — сравнение моделей по горизонтам 1/3/6/12 мес.;
- `03_changepoints.ipynb` — шоки на реальных примерах МО;
- `04_interpretation.ipynb` — SHAP-разбор прогнозов.

Основная логика живёт в `src/`, ноутбуки только вызывают её и визуализируют.
